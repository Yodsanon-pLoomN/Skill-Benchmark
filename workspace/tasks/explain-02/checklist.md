# Checklist — explain-02

## ความถูกต้อง/ความครบถ้วน

1. คำตอบระบุว่า `findBookingsForDay` กรองเฉพาะ booking ที่ status เป็น CONFIRMED เท่านั้น (ไม่รวม CANCELLED)
2. คำตอบระบุว่าการกรองตามวันที่เป็นการเช็ค overlap กับช่วงของวันนั้น (`startsAt <= dayEnd && endsAt >= dayStart`) ไม่ใช่การเช็คว่า booking ต้องอยู่ในวันนั้นทั้งหมด
3. คำตอบ trace ค่า cursor ที่ถูกต้องสำหรับ booking ที่ 1 (09:00-10:00): ผลัก free interval `{00:00–09:00}` แล้ว cursor ขยับเป็น 10:00
4. คำตอบ trace ค่า cursor ที่ถูกต้องสำหรับ booking ที่ 2 (09:30-11:00): ไม่ผลัก free interval ใหม่ (เพราะ `startsAt` 09:30 ไม่มากกว่า cursor 10:00) แล้ว cursor ขยับเป็น 11:00
5. คำตอบระบุ final free intervals ที่ถูกต้องคือ `{00:00–09:00}` และ `{11:00–dayEnd}`
6. คำตอบอธิบายเหตุผลว่าทำไมขั้นตอนที่ 2 ไม่ผลัก free gap ปลอม (ไม่ใช่แค่บอกผลลัพธ์เฉยๆ)
7. คำตอบยกตัวอย่างที่เป็นรูปธรรมด้วย booking ต่อเนื่องกันพอดี (back-to-back เช่น 09:00-10:00 กับ 10:00-11:00) เพื่ออธิบายผลของการเปลี่ยน `>` เป็น `>=`
8. คำตอบระบุผลที่ผิดพลาดที่ถูกต้องจากการเปลี่ยนเป็น `>=`: เกิด free interval ความยาวศูนย์ (เช่น 10:00–10:00) ที่ขอบเขตระหว่าง booking ทั้งสอง ไม่ใช่การ crash

## คุณภาพ

9. คำตอบเรียงลำดับตามคำถามทั้ง 3 ข้อ และข้อ 2 มีตารางหรือ step-by-step แสดงค่า cursor แต่ละขั้นตอนอย่างชัดเจน (ไม่ใช่แค่บรรยายกว้างๆ)
10. คำตอบใช้ศัพท์ทางเทคนิคถูกต้องสม่ำเสมอ
11. ไฟล์ในโปรเจกต์ไม่ถูกแก้ไข/สร้างใหม่ (ตรงตามคำสั่ง "do not change any files")
