# Candidate skills

Put the skill folders you want to benchmark here (`skill_type` `file`, `file-command` or `combo`).
Each skill is one folder with a `SKILL.md` inside:

```
workspace/skills/
  verification-before-completion/
    SKILL.md
```

Example: copy `skills/verification-before-completion/` from <https://github.com/obra/superpowers>.

Plugins that are switched on with a slash command (e.g. Caveman, `skill_type` `command`) are
installed with `/plugin install` instead and do not go here.

Everything in this folder except this README is git-ignored, because the skills belong to their authors.
